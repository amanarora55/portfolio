## 🛠️ About this repo

This is the source of my one-page portfolio. It's designed so a recruiter or hiring manager gets the full picture in under 10 seconds, and it's a working example of how I build frontends.

**Sections on the page:** a hero with a typewriter headline and an "At a glance" card, a tech-stack marquee, animated impact metrics, an expandable experience timeline, skills, projects, education & recognition, and contact (with copy-to-clipboard email).

**Built with:** Next.js 16 (App Router, static) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · Framer Motion · Lucide & Simple Icons

**Craft details:**
- Accessible: semantic sections, `aria-current` navigation, screen-reader text for animated content, and visible focus states
- Respects `prefers-reduced-motion`, so every animation switches off for users who ask for it
- Responsive from 390px phones up to wide desktops
- All content lives in one typed data file, so updating the site means editing data, not markup

### Run locally

```bash
npm install
npm run dev      # http://localhost:4321
```

Production build:

```bash
npm run build
npm start        # http://localhost:4321
```

### Updating content

- **Text and data:** edit [`src/data/resume.ts`](src/data/resume.ts). In bullet text, `**double asterisks**` render as highlighted metrics.
- **Resume PDF:** replace [`public/Aman-Arora-Resume.pdf`](public/Aman-Arora-Resume.pdf).
- **Hero photo:** replace `public/hero-desk.jpg`.
